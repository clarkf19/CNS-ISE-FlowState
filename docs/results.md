# Evaluation Results

Generated by `python -m eval.benchmark` on 2026-10-01 (Python 3.14.5, Windows-11-10.0.26200-SP0; 500 requests, 4 concurrent clients). All traffic is over loopback TCP, so latencies show the cost of the gateway itself, not network distance.

## Attack blocking

**100%** of attack scenarios blocked; legitimate traffic continued normally.
